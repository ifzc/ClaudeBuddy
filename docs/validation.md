# 验证范围

初次桌面验证环境：Windows 11 x64；飞书 8.2.0.73；微信 4.1.7.59；电脑系统时区为 America/Phoenix 对应的 Windows 时区。

## 自动验证

- 配置默认值互不共享；部分配置保留另一应用默认值；非法数据形状、时区和路径类型被拒绝。
- 飞书只选择 renderer；微信的 OCR、播放器和小程序进程不选择；不同控制器的子进程互不干扰。
- 使用独立 Python 子进程实际调用 Windows API，覆盖北京、亚利桑那和纽约的时区读数、一月/七月转换、UTC 不变及卸载后恢复。
- 两个真实测试进程同时使用不同的时区；恢复其中一个，另一个仍保持自己的时区。

## 已完成的桌面观察

| 项目 | 结果 |
| --- | --- |
| 飞书聊天列表 | 同一历史时间按预期偏移 15 小时 |
| 飞书日历 | 显示 GMT+8 和对应当前时间线 |
| 飞书辅助进程 | 保持系统时区 |
| 飞书恢复普通启动 | 旧单应用版本已实测 |
| 微信聊天列表 | 两个未更新的历史会话均按预期偏移 15 小时，包括跨日变化；用户确认显示正确 |
| 微信主进程 | 独立探针读到 China Standard Time，Bias = -480 |
| 微信辅助进程 | 独立探针仍读到系统时区 |
| Windows 系统时区 | 验证前后保持原样 |

聊天截图、个人会话名称和实际消息内容不公开。
